How to Run Encarta on Windows 11, and Why It Ended

By Theo Lindqvist · Updated November 22, 2026 · First published March 26, 2026 · 9 min read

Microsoft Encarta can run on Windows 11, most reliably inside a free VirtualBox machine with Windows XP or Windows 7, using the Microsoft Student with Encarta Premium 2009 disc image from the Internet Archive. Microsoft stopped selling Encarta in June 2009 and closed MSN Encarta on October 31, 2009, leaving Wikipedia and web search in its place, so no official version exists in 2026.

Can Encarta run on Windows 11?

Sometimes, but the dependable way to run Microsoft Encarta on Windows 11 is inside a free virtual machine with Windows XP or Windows 7 as the guest. Microsoft never released an Encarta built for Windows 10 or 11, and it stopped selling every edition in June 2009.

Which edition you have decides how hard this is. Windows 11 runs 32-bit programs, and the last editions of Encarta are 32-bit, so a direct install can work. Developer Scott Hanselman wrote in 2019 that an old Encarta disc "installed just perfectly on my latest Window 10 machine," and OSNews reported in 2019 that the 2009 release ran fine on Windows 10. Others hit setup errors, and one user on Microsoft's own Q&A forum reported that the Encarta package with the dictionary would not install on Windows 11 at all.

The early discs are a different case. The first editions were written for Windows 3.1, and Microsoft's support documentation is blunt that 64-bit versions of Windows "don't support 16-bit components, 16-bit processes, or 16-bit applications." Windows 11 only comes in 64-bit, so an Encarta 94 or 95 disc needs an older Windows in a virtual machine or nothing. That is why the virtual machine is the method worth learning, one step at a time.

How to install Encarta on Windows 11, step by step

The method costs nothing beyond a Windows license you already own, and most of the time goes on waiting for installers.

1. Try the direct install first. If you have Encarta 2009 or 2008, mount the disc image on Windows 11 by double-clicking the ISO, right-click setup.exe, open Properties, then Compatibility, tick "Run this program in compatibility mode for" Windows XP (Service Pack 3), and run it as administrator. If it installs and opens, you are done.

2. Install VirtualBox. Oracle's VirtualBox is free and runs on Windows 11. Create a new 32-bit Windows XP or Windows 7 machine with at least 1 GB of memory and enough virtual disk for Windows plus a full Encarta install.

3. Install the guest Windows. You need your own Windows XP or Windows 7 install disc or image and its product key, since Microsoft no longer sells either. Keep the guest offline: it gets no security updates and Encarta needs no internet.

4. Download the right Encarta image. The English "Microsoft Student With Encarta Premium 2009 DVD (ISO)" on the Internet Archive is a 3.0 GB file, added in February 2021. Avoid sites that promise an "Encarta download" behind a keygen or an installer of their own.

5. Mount and install. In VirtualBox, attach the ISO to the virtual optical drive, then run setup inside the guest. The uploader's listing asks for 1 GB of RAM and 2.0 GB of free disk space, or 4.8 GB for a full installation, which copies the whole DVD so it never asks for the disc again.

6. Mind the Internet Explorer dependency. Encarta's setup and its web features leaned on Internet Explorer for years. Microsoft's support note for Encarta 99 explained the error "Your system is missing the required Setup engine" by saying it "can occur if you do not have a Web browser installed," and the fix was Internet Explorer 4.0 from the Encarta disc. Windows XP and Windows 7 ship with Internet Explorer, which is one more reason they make the best guests.

If the installer bar sits still for a long time, leave it alone: a commenter on Hanselman's post described Microsoft's student installer as having "a progress bar that does nothing for a very long time, before jumping to the end." Once it finishes, the next choice is which edition was worth installing in the first place.

Which Encarta edition should you download?

For most people the answer is the last English release, Encarta Premium 2009, sold inside Microsoft Student. It has the most content, more than 62,000 articles, and the uploaded English copy is a single DVD image. Older editions are worth it for nostalgia: the 1990s interface, the narrated videos, the original MindMaze.

Is Encarta free now, and can you still buy it?

Encarta is free in practice: the disc images on the Internet Archive cost nothing, and no company sells or supports Encarta in 2026. Microsoft has not sold or hosted it since 2009, and it never licensed the name to another publisher.

The wind down ran across a single year. Microsoft announced the end in March 2009, sales of Encarta Premium and Microsoft Student stopped worldwide in June 2009, and the MSN Encarta websites went dark on October 31, 2009 in every country except Japan, where the site ran to December 31, 2009. The Encarta online dictionary lasted until 2011. It was switched off rather than sold, the same ending other parts of the MSN family got, including MSN Messenger.

Running it offline means the content is frozen in 2008: every population figure, head of state and space mission stops there. The yearbook updates that once downloaded over the internet are gone with the servers, although some update files have been preserved on the Internet Archive as well.

Where to find one today: the disc images at the Internet Archive are the sensible first stop. If the physical box is the point, Encarta CD-ROM and DVD editions from the mid 1990s through 2009 show up regularly in vintage software listings on Etsy, loose discs far more often than sealed copies, and no edition is scarce. The edition parents hunt for most often is the one made for children.

What was Encarta Kids, and is it still available?

Encarta Kids is not available as a product in 2026; it lives on only inside the Encarta discs from 2005 to 2009, which means it installs with them. Microsoft introduced it in Encarta Reference Library Premium 2005, announced on July 7, 2004 for students "age seven and up."

It was a separate, simpler encyclopedia with its own look: more than 500 new articles in 10 categories, including Animals, Everyday Life, History and Science, with extensive multimedia content. Karla Tharin, Microsoft's Encarta product manager, pitched it in the 2004 announcement with the line "We know parents aren't always able to act as teacher and tutor."

To get it back, install a 2005 or later edition by the steps above; Encarta Kids comes with it. The Internet Archive holds an English "Encarta 2005 Encyclopedia Deluxe With Encarta Kids" set of three CD images alongside the 2009 DVD. Encarta Kids was the last new idea in a product that had started a decade earlier with an expensive bet.

The $395 disc built on Funk and Wagnalls

Encarta's articles did not start at Microsoft. The company went to Encyclopaedia Britannica first, in 1985, and was turned down. By 1989 Microsoft had a non-exclusive deal for the 29-volume Funk and Wagnalls New Encyclopedia instead, and that text became the basis of the first edition. In the late 1990s it added Collier's Encyclopedia and the New Merit Scholar's Encyclopedia, bought from Macmillan.

Encarta arrived on March 22, 1993 at $395, dropped to $99, and was then handed out with new computers, including the wave of machines that followed the Windows 95 launch. It also gave people a reason to buy a PC with a CD-ROM drive and a sound card at a moment when multimedia hardware needed selling.

What people remember is MindMaze, the trivia game inside the encyclopedia, where the player explores a castle by answering questions whose answers sit in Encarta's own entries. Microsoft was shipping a lot of friendly consumer software then, including Clippy, and Encarta was the one that earned goodwill rather than jokes. The people who built it already suspected how it would end.

What replaced Encarta, and why did Microsoft give up?

Wikipedia replaced Encarta, with web search covering the rest. In January 2009, Wikipedia took 97 percent of the visits United States web users made to online encyclopedias, according to the measurement firm Hitwise; MSN Encarta was second with 1.27 percent and Britannica.com fifth at 0.57 percent.

Microsoft said as much in its 2009 notice to customers: "People today seek and consume information in considerably different ways than in years past." Encarta paid editors, licensed photographs and pressed discs once a year, while Wikipedia was written by volunteers, updated within hours and free. Years of giving Encarta away with new PCs had already taught buyers to treat an encyclopedia as a free extra.

Tom Corddry, who ran Microsoft's multimedia group, told Business Insider in 2015: "We knew from the beginning that we were a temporary business, eventually to be overtaken by the internet." He was right about the ending. The odd part is the epilogue: the encyclopedia that the internet killed now survives because the internet keeps a copy, waiting for anyone with a virtual machine and an afternoon. Frequently Asked Questions

Can Encarta run on Windows 11?

Microsoft Encarta 2008 and 2009 can sometimes be installed directly on Windows 11 in Windows XP compatibility mode, because they are 32-bit programs, but results vary. The reliable method is a free VirtualBox machine running Windows XP or Windows 7, with the Encarta Premium 2009 disc image from the Internet Archive mounted inside it. Editions from 1993 to 1995 were written for 16-bit Windows 3.1 and will not run on 64-bit Windows 11 at all.

Is Encarta free now?

Microsoft Encarta has no official free release, but no one has sold it since June 2009, and English disc images such as the 3.0 GB Microsoft Student with Encarta Premium 2009 DVD are hosted at no cost on the Internet Archive. Used retail discs are also cheap and common in vintage software listings.

Is Encarta Kids still available?

Encarta Kids is not sold or hosted anywhere in 2026, but it is included on every Encarta edition from Encarta Reference Library Premium 2005, released in July 2004, through Encarta Premium 2009. Installing one of those editions, for example in a Windows XP virtual machine, restores Encarta Kids with its 500-plus articles for children age seven and up.
