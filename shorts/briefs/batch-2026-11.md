# Shorts batch, November 2026

Voice: Pedro records each approved script. Every number comes from the linked post. No em dashes.
Target 50 to 60 seconds. Each numbered line is one beat; leave a one-second pause between lines when
recording, and simply repeat a line if you stumble (the edit keeps the best take).

Every video opens with three hooks in sync in the first three seconds: words on screen that read in
under a second, motion inside the first few frames, and a sound event on frame zero (never a silent
start). Sound effects are synthesized for the edit, never lifted from the products or from libraries
with unclear rights.

Structure used in all six: a hook that sounds impossible, an open loop inside the first five seconds,
rising specifics, a re-hook near the middle, the payoff, then a present-day kicker that closes the loop
and, where possible, flows back into the first line so the Short replays cleanly.
