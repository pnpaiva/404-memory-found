Windows 95 Launch: The $300 Million Night of 1995

2026-04-05 | Updated 2026-09-20 | By Theo Lindqvist | 6 min read

Microsoft released Windows 95 on August 24, 1995 behind a marketing campaign reported at $300 million, and stores opened at midnight to sell a $209.95 box of software. It moved about 1 million copies in four days and 40 million in its first year. Windows 95 is no longer a supported product: Microsoft ended support on December 31, 2001, and the only way to run it in 2026 is emulation.

What did Windows 95 actually change about using a PC?

Before August 1995, a PC running Windows 3.1 dropped you into Program Manager, a grid of boxes inside boxes, with MS-DOS underneath it. Opening a program often meant knowing a path and typing it. There was no single obvious place to start.

Windows 95 added one. The Start button sat in the bottom left corner, and a taskbar ran along the bottom showing every open program by name. A minimized window no longer vanished. Right-clicking finally did something useful almost everywhere.

Long file names arrived with it. The old eight-character limit turned a school paper into ENGESS~1.DOC; Windows 95 let it be English Essay Final Draft.doc. Windows Explorer replaced File Manager, and a My Computer icon on the desktop put the hard drive, the floppy drive and the CD-ROM drive in one window.

Underneath, Windows 95 moved consumer PCs to a largely 32-bit design while keeping 16-bit code for compatibility, and it introduced Plug and Play, which was meant to detect new hardware instead of making owners set IRQ numbers by hand. The first version of DirectX shipped in the same period and set Windows up as the PC gaming platform it still is.

Why did Microsoft spend $300 million on an operating system?

To make a piece of software the news rather than a product release. The Windows 95 campaign was reported at $300 million, and Goldman Sachs analyst Rick Sherlund told The Spokesman-Review on launch day, "I think this is unprecedented in breadth and scope."

The money bought stunts that had nothing to do with computing. The Empire State Building in New York was lit in the colors of the Windows logo. In Toronto, a 328-foot Windows 95 banner hung from the CN Tower. In Britain, Microsoft paid for 1.5 million copies of The Times to be handed out free, roughly twice the paper's daily circulation at the time.

It also bought music and television faces. Microsoft licensed the Rolling Stones' 1981 single "Start Me Up" for the advertising; press reports in 1995 put the fee at between $8 million and $14 million, and lower figures have circulated since. Microsoft then commissioned a 30-minute tape, the Microsoft Windows 95 Video Guide, starring Jennifer Aniston and Matthew Perry of Friends, and billed it as the first "cyber sitcom." It sits on the Internet Archive now and it has aged badly.

None of this was normal for software in 1995. Apple would not saturate popular culture on that scale until its portable music campaigns the following decade.

What happened on launch night, August 24, 1995?

Stores opened at midnight. CompUSA and other chains ran launch-night events, and people queued outside to buy a boxed operating system with a suggested retail price of $209.95, or $109.95 as an upgrade from Windows 3.1, according to The Seattle Times in June 1995. Street prices were often lower.

Microsoft's own event ran on the lawn of its Redmond campus. More than 12,500 people were invited, a crew of over 200 spent 20 days building the site, and Jay Leno co-hosted with Bill Gates. Gates got the line of the night: "Windows 95 is so easy even a talk-show host can figure it out."

The selling was real, not just the staging. UPI reported that Windows 95 moved about 1 million copies at retail in its first four days. Seven million copies went out in the first five weeks, and Microsoft said it had shipped 40 million units worldwide by the first anniversary in August 1996.

The box mattered too. Buyers got a CD-ROM or, if their PC had no CD drive, 13 floppy disks in a high-capacity format, along with a manual and a holographic certificate of authenticity. The first thing most of them heard after setup finished was the startup chime Brian Eno wrote.

What went wrong with Windows 95?

It crashed. The bridge between 16-bit and 32-bit code was fragile, memory management was thin, and running too many programs at once could take the whole machine down. Most applications had no autosave in 1995, so a lockup cost whatever was on screen.

Plug and Play worked often enough to matter and failed often enough to earn the nickname Plug and Pray. Sound cards, modems and printers fought over the same resources, and clearing a conflict could mean editing a configuration file or driving back to the store for different hardware.

The published requirements also understated what the system needed. Microsoft listed a 386DX processor, 4 MB of RAM and 50 to 55 MB of free disk space, then recommended a 486 with at least 8 MB. Plenty of buyers upgraded and found that their machine technically ran Windows 95 and practically could not.

Compatibility cut both ways. Some Windows 3.1 programs misbehaved, and DOS games in particular could be awkward, which is how households ended up dual-booting. That problem never fully went away, as anyone trying those titles on Windows 11 finds out.

Can you still run Windows 95 in 2026?

Not as a supported product. Microsoft ended mainstream support for Windows 95 on December 31, 2000, and extended support on December 31, 2001, which made it obsolete under the company's lifecycle policy. It has not been sold or patched since, and Microsoft still owns the code.

What people do instead is emulate it. The Internet Archive hosts a pre-installed Windows 95 disk image that boots in a browser tab through DOSBox, and browser emulators built on the v86 engine run the same thing by translating x86 instructions into WebAssembly. Locally, 86Box, PCem and VirtualBox will all boot a Windows 95 image on current hardware. All of it is slower and buggier than the real thing was on period hardware, and none of it belongs on the open internet.

The design outlived the code. Windows 98 arrived in June 1998, Windows XP moved consumer Windows onto the NT kernel in October 2001, and Windows 8 tried to drop the Start menu in 2012. Users pushed back hard enough that Microsoft put it back in Windows 10 in 2015. The taskbar, the Start button, the clock in the corner and the recycle bin are all still roughly where Windows 95 put them.

The internet part landed as well. Windows 95 shipped without a web browser, but it carried a TCP/IP stack, and Internet Explorer arrived first in the Plus! add-on pack and later inside the operating system itself. That decision fed the antitrust case against Microsoft and the collapse of Netscape Navigator.

Frequently Asked Questions

When did Windows 95 come out?

Windows 95 went on sale on August 24, 1995, with stores across the United States opening at midnight to sell it. Microsoft launched it at an event on its Redmond campus co-hosted by Bill Gates and Jay Leno.

How much did Windows 95 cost when it launched?

Windows 95 carried a suggested retail price of $209.95 for the full version in 1995 and $109.95 for the upgrade aimed at people already running Windows 3.1, according to The Seattle Times. Shops frequently sold both for less.

Can you still run Windows 95 in 2026?

Only through emulation. Microsoft ended support for Windows 95 on December 31, 2001, and the operating system has not been sold or patched since. Emulators such as 86Box and pre-installed browser images on the Internet Archive will still boot Windows 95 in 2026.
